# Secure Login System with Password Hashing (bcrypt)

A cybersecurity-focused web application that demonstrates secure user authentication using **Python Flask**, **SQLite**, and **bcrypt**. The project implements industry-standard password hashing to protect user credentials and follows secure coding practices to reduce common web application vulnerabilities.

## Features

* Secure user registration
* Password hashing using bcrypt
* User login authentication
* Session management
* Logout functionality
* SQLite database integration
* SQL injection prevention using parameterized queries
* Password validation
* Responsive HTML/CSS interface

## Technologies Used

* Python 3
* Flask
* SQLite
* bcrypt
* HTML5
* CSS3

## Project Objectives

* Learn secure authentication techniques.
* Understand password hashing and verification.
* Implement secure session handling.
* Follow cybersecurity best practices in web development.

## Future Enhancements

* Two-Factor Authentication (2FA)
* Email verification
* Password reset functionality
* Login attempt limiting
* Audit logging
* CSRF protection
* Role-based access control

## Educational Purpose

This project was developed as part of a cybersecurity internship to demonstrate secure authentication mechanisms and web application security best practices.
